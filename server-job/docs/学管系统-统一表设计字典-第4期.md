## 五、这份字典怎么用

| 场景 | 做法 |
|---|---|
| 要重建某张表 | 找到该表章节 → 按「列名 / 类型 / 可空 / 来源」逐列照抄 → 有坑的按「坑位总清单」处理 |
| 不确定某列含义 | 查该列的「备注」列；标了「值才知道」的必须问斌哥或读代码 |
| 删老库之前 | 确认本章 + 附录已覆盖你需要的全部表 |
| 结构变了 | 重跑两个脚本（先重新导出 all-schemas.json） |

### 重新生成方式

```bash
cd server-job
node scripts/_p4-gen-dict.cjs            # 主流程（统一表 + 坑位）
node scripts/_p4-gen-dict-appendix.cjs  # 附录（另外 5 个库）
```

★ 本文件由脚本生成，**不要手改** —— 手改会在下次生成时被覆盖，
★ 且会和真实库结构不同步。原始数据在 `server-job/_p4-schema-dump/all-schemas.json`
（118 张表 / 2520 列，含列名、类型、可空性、默认值）。

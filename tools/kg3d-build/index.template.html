使用说明

xgxt 代码知识图谱 · 基于 codebase-memory-mcp 解析结果构建

🖱️ 交互操作

  • 旋转 / 平移 / 缩放：左键拖拽旋转视角，右键拖拽平移，滚轮缩放。
  • 查看节点：单击任意节点，右侧面板显示其代码位置、元数据、各类关系与调用关系；关系条目均可点击跳转。
  • 调用方向：选中节点后，蓝色边为「它调用的」（粒子流向被调用方），橙色边为「调用它的」。
  • 搜索：顶栏搜索框支持按节点名称 / 文件路径 / 限定名模糊搜索，回车跳转第一个结果。
  • 筛选：左下角图例中点击节点类型可显示 / 隐藏该类节点；顶栏可切换配色依据（类型 / 工程 / 复杂度 / 连接度）。

📊 数据说明

全量图谱共 12,410 个节点、37,847 条关系边。为降低视觉噪音，本视图剔除 4,564 个 Variable（变量）节点，展示 7,848 个代码实体节点与 22,197 条关系边；变量级的定义 / 使用关系可通过源码检索补充查看。节点按所属工程（server-job / web-job / shared-types）分为三簇，目录 → 文件 → 函数 / 模块的层级关系决定初始布局。

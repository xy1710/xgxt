改版设计原则

全部来自 UI 审查报告，四条原则管住全站：

按任务组织，不按模块堆砌

侧栏只放「工作台 + 7 个模块」，登录先落角色工作台；页面内的选择交给页内二级导航，一屏放得下。

看得清：对比度与字号达标

次要文字 #6B5C58（5.9:1）、弱文字 #8A7B76（4.6:1），全部过 WCAG AA；字号上提一级，12px 为全站下限。

一套组件，全站同构

KPI 卡、表格、筛选栏、弹窗各只有一种长相；圆角统一 8/12px；一屏一个强调色，品牌红只给主动作。

容错：可撤销、有反馈

破坏性操作 5 秒内可撤销；骨架屏代替转圈；空状态给插图 + 文案 + 主动作，不甩一句「暂无数据」。

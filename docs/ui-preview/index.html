设计原则 · 为什么看着不刺眼

LOGO 的红（#DF1115）饱和度高，大面积铺会疲劳。三条做法解决冲突：

暖中性打底，红色只做点缀

页面底色用带一点暖意的灰白（#F6F3EF），文字用 LOGO 里的深暖灰（#443432）而非纯黑。红色只出现在按钮、选中态、关键数据上，全屏红色面积 < 5%。

品牌红柔化后再使用

LOGO 红 #DF1115 直接做按钮太艳，界面主色柔化为 #CD3A33：保留同一色相家族，降低明度与饱和冲击，悬停再加深到 #B22A23，层次一致不跳脱。

圆角 + 柔阴影 + 无重边线

按钮、输入框、卡片统一 8–14px 圆角；阴影用暖灰调（rgba(68,52,50,…)）而非黑色，边框用比内容浅两级的暖色线，界面整体「软」下来。
